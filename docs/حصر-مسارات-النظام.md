# حصر مسارات النظام ومراجعتها

هذا حصر ساكن لمسارات HTTP المعرّفة في الشيفرة وقت المراجعة، مع وظائف التنقل والبث؛ لا يعني أن كل سيناريو أو جهاز أو إعداد شبكة اختُبر، ولا يثبت خلو النظام من العيوب. صلاحيات «جلسة» تحتاج أيضًا مراجعة فلتر المالك داخل المسار؛ حساب المخازن مقيد مركزيًا بالمخازن والجلسة وكلمة مروره في `requireAuth`.

## الواجهات والبث

- لوحة المكتب `/`: مركز العمليات والخريطة، السجل الشهري، المؤشرات، الزيارات والطلبيات، العملاء، المبيعات والفواتير والمرتجعات، المخازن، حسابات المكتب، فريق الميدان، المساعد الذكي والهوية. حساب المخازن يرى نطاقه فقط.
- تطبيق المهندس `/app/` وتطبيق الهاتف: الرئيسية والوردية، الزيارات والطلبيات، عملائي، حسابي والمزامنة. صفحات الخصوصية `/privacy` و`/delete-account` عامة، والحذف الفعلي عبر API محمي.
- Socket.IO: قناة المدير والمستخدم تخضع للتحقق من الجلسة ودور الحساب، والبث لا يحل محل إعادة تحميل البيانات المحفوظة.
- fallback الواجهة الثابتة في `server/src/index.ts`، وfallback تطبيق المهندس في `server/src/engineer-web.ts`؛ المسارات غير المعروفة تحت `/api` ترد 404 JSON.

## فحص المخاطر والاختبارات

- الجلسات والصلاحيات وCSRF: `authz.test.ts`, `auth-cookie-csrf.test.ts`, `client-separation.test.ts`, `warehouse.test.ts`؛ اختبارات تلقائية وليست اختبار اختراق.
- العملاء، الأصناف والطلبيات: `customer-book.test.ts`, `catalogue.test.ts`, `orders.test.ts`, `order-delivery.test.ts` واختبارات واجهة الطلبية. ثُبّت فحص المسودة والعميل والصنف داخل قفل الإرسال والإنشاء، ومُنع تعديل طلبية أُرسلت أثناء انتظار القفل. أصبح تعارض معرف إنشاء الطلبية الجديدة مع بيانات مختلفة مرفوضًا؛ وقت التسجيل مستثنى من البصمة لتوافق إعادة إرسال الهاتف. الطلبات القديمة بلا بصمة أصلية تحتفظ بسلوك إعادة المحاولة القديم ولا يمكن إثبات تطابق إدخالها الأصلي.
- المبيعات، الحسابات والمرتجع والمخزون: `sales.test.ts`, `sales-corrections.test.ts`, `returns.test.ts`, `accounting-retry-race.test.ts`, `warehouse.test.ts` واختبارات الواجهات. لم تفحص هذه الاختبارات قاعدة الشركة ولا تثبت مطابقتها للدفاتر.
- الوردية، الزيارات والمواقع والطوابير: `visit-offline.test.ts`, `shift-reconciliation.test.ts`, `gps-offline-replay.test.ts`, `native-gps-outbox.test.ts`, `route-display.test.ts` واختبار المتصفح. الخريطة تقديرية، والمسافات حساب مستقل، وتحتاج تجربة هاتف حقيقي؛ ليس ممكنًا استرجاع قراءات لم تُحفظ.
- التقارير والتصدير والإشعارات: `exports.test.ts`, `kpi-daily-bucket.test.ts`, `push-api.test.ts`, `order-invoice-notices.test.ts`. push أفضل محاولة ولا يضمن التسليم.
- لا تشمل المراجعة تشغيل النظام على جهاز الشركة، تدقيق كل بيانات الإنتاج، كل السباقات أو كل حالات انقطاع الشبكة، اختبار اختراق، اختبار GPS ميداني أو اختبار استعادة نسخة إنتاج. عند التحديث يلزم نسخة احتياطية متسقة وخطة استعادة، وتوافق توقيع APK وعدم حذف تطبيق يحتوي طابورًا غير متزامن.
