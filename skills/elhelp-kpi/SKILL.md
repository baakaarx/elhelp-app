# ElHelp KPI — مؤشرات الأداء

## المؤشرات المحسوبة
من `GET /api/kpis?from=&to=` لكل مهندس:
- `distanceMeters` — المسافة التقديرية (بعد فلترة الدقة والقفزات)
- `visits` / `visitsCompleted` — إجمالي الزيارات والمكتملة
- `avgVisitSeconds` — متوسط مدة الزيارة
- `reports` / `dailyReports` — التقارير السريعة واليومية
- `collected` — إجمالي التحصيل (من `visits.amount` + `reports.amount`)
- `daysWithData` — أيام النشاط الفعلي

## كيف يفسرها الـ Agent (بدون API)
- **إنتاجية منخفضة**: زيارات <2/يوم لمدة 3 أيام → "يحتاج متابعة ميدانية"
- **زيارات قصيرة جداً**: متوسط <5 دقائق → "احتمال تسجيل صوري — راجع GPS الزيارة"
- **تحصيل عالي + زيارات قليلة**: كفاءة ممتازة
- **لا تقارير يومية**: رغم وجود زيارات → "تأخر إداري — تذكير"
- **مقارنة الفريق**: يرتب المهندسين ويبرز الأفضل والأقل، مع تصدير CSV يفتح في Excel

## قوالب النصائح (عربية)
- "أحمد: 5 زيارات/يوم، 18كم، تحصيل 12,500ج — أداء متوازن"
- "محمد: متوسط زيارة 3 دقائق فقط — راجع جودة الزيارات"
- "سارة: 0 تقرير يومي هذا الأسبوع — تذكير بإرسال التقرير"

## الخصوصية
- لا يستخدم بيانات `is_demo` في التقييم الفعلي
- يحترم `RETENTION_DAYS` — لا يحلل بيانات محذوفة
