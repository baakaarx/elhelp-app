# حالة مراجعة الفرع

**آخر تحقق:** ٢ نوفمبر ٢٠٢٦
**النطاق الحالي:** APK لمهندسي Android، وموقع مهندس مخصص لمهندسي iPhone على Safari، ولوحة ويب منفصلة للمدير؛ وواجهة API مشتركة ترفض استخدام الدور من العميل غير المخصص له. لا يوجد بناء iOS أصلي ضمن خطة التوزيع الحالية.

## خلاصة المراجعة الرجعية

راجعت التغييرات العابرة بين الخادم واللوحة وتطبيق الهاتف، مع التركيز على الهوية والصلاحيات والجلسات وCSP وOAuth والزيارات دون اتصال وGPS والطوابير والنسخ الاحتياطي والتنظيف والتقارير. أصلحت خلال الجولة العيوب التي أمكن إعادة إنتاجها، وأضفت اختبارات دائمة لها:

- الجلسة المستخدمة تنزلق مع الاستخدام، لكن تنتهي حتمًا بعد ٣٠ يومًا من إنشائها؛ نجح اختبار السقف المطلق واختبارات انتهاء الجلسة وتسجيل الخروج.
- لا يُعاد استخدام آخر GPS موثوق بعد أن يعلّم نظام التشغيل موقعًا محاكى؛ أُضيف اختبار لصلاحية الكاش وإبطاله.
- ترتيب صندوق SQLite يحسم تساوي وقت التسجيل بواسطة `rowid`، بحيث يصل check-in قبل check-out حتى لو سُجّلا في millisecond واحدة، وتُرسل الزيارات قبل تراكم نقاط GPS. إذا فشل check-in لأي سبب، يبقى check-out معلقًا حتى ينجح تسجيل الزيارة ولا يُنشأ رفض 404 تابع؛ لا يمنع ذلك إرسال التقارير غير المرتبطة.
- حدّ صندوق المتصفح أصبح مرنًا: لا تُحذف الزيارات/التقارير المهمة بصمت عند تجاوز ٥٠٠ عنصر، وفشل الكتابة بسبب امتلاء التخزين يُظهر خطأ بدل الادعاء بأن الطلب حُفظ. بيانات الصندوق التالفة لا تُعامل كقائمة فارغة أو تُستبدل. حالة «غير متزامن» تُمحى عند مزامنة الزيارات نفسها، وخروج الحساب يحذّر قبل حذف عمل غير مرسل.
- تُربط العناصر المعلقة بالحساب الذي أنشأها؛ تبديل الحساب لا يرسلها باسم صاحب جلسة آخر. إعادة المحاولة اليدوية تزيل الإيقاف مؤقتًا، والفشل المؤقت يعود للمحاولات التلقائية. حذف الحساب يوقف التتبع قبل تنظيف الطابور المحلي.
- بروفايل EAS للإنتاج يرفض عنوان API غير HTTPS أو loopback؛ أُضيفت اختبارات config تقبل عنوان VPS عبر HTTPS وترفض HTTP و`::1`.

بقي فصل الأدوار كما طلب المستخدم: `/` لوحة المدير و`/app/` موقع المهندس. أُضيف تصدير Expo Web إلى بناء المشروع، وخدمة ثابتة للواجهة مع deep-link fallback لا يسقط على لوحة المدير، وCSP منفصل، واختبارات رجوع للصفحة والأصول والمسارات العميقة. نشر موقع iPhone على نطاق فرعي منفصل موصى به لعزل `localStorage` عن جلسة المدير. تسجيل الدخول أو الجلسة من عميل الدور الخطأ يظل مرفوضًا.

## نتائج التحقق على الشجرة الحالية

- `npm ci` — اكتمل بنجاح (٦٧٣ حزمة مضافة).
- `npm ls minimatch @expo/fingerprint --all` — `@expo/fingerprint@0.21.10` يستخدم override إلى `minimatch@11.0.8` كما هو مقفل في lockfile.
- `npm audit` — **صفر ثغرات**.
- `npm test` — **٢٤١/٢٤١** ناجحة، بينها اختبارات CSP وعزل صفحة المهندس وأصولها ومساراتها العميقة، وملكية صندوق المزامنة والاحتفاظ بعناصره المرفوضة أو التالفة.
- `npm run typecheck` — ناجح للخادم ولوحة المدير وتطبيق الهاتف.
- `npm run build` — ناجح: `server/dist` و`dashboard/dist` وتصدير Expo Web إلى `mobile/dist` على قاعدة `/app` مع API نسبي من الأصل نفسه. Docker CLI غير مثبت هنا، لذلك لم يُبنَ image من `server/Dockerfile`.
- اختبار الخادم المبني على قاعدة مؤقتة ثم smoke HTTP حيّ — **١١٤/١١٤**، بما يشمل لوحة المدير، حزمة المهندس والخط المحلي وdeep links وعودة OAuth إلى `/app` وCSP وفصل COOP بين المدير ونافذة OAuth ورفض خلط الأدوار والزيارات دون شبكة والتقارير وExcel وSocket.IO وحذف الحساب بعد إعادة ربط الجهاز.
- فحص Expo السابق: prebuild Android نجح، لكن Gradle لم يُشغّل لغياب JDK/Android SDK؛ لم يُنتج APK. اختبارات EAS release guard نجحت ٣/٣. فحص iOS السابق كان إعدادًا فقط وليس IPA، ولا يدخل ضمن خطة التوزيع الحالية.
- `git diff --check` — ناجح.

## ما بقي قبل اعتبار النشر الفعلي مكتملًا

- لا يوجد عنوان VPS النهائي عبر HTTPS؛ ما زال مطلوبًا لإنتاج APK قابل للاستخدام. المثال في `mobile/.env.example` مجرد قيمة إرشادية، وليس عنوانًا صالحًا. التصدير الويب تعمّد استخدام API نسبي من نطاق المهندس.
- `minimatch@11.0.8` إصلاح أمني اضطراري داخل `@expo/fingerprint`، وخارج النطاق المعلن له `^10.2.6`. نجح fingerprint وExpo export وAndroid prebuild، لكن لا يوجد بناء Gradle أو APK نهائي؛ البيئة الحالية بلا JDK وAndroid SDK/ADB، وأمر `npx expo install --check` السابق تعذّر بسبب TLS.
- لم تُضبط بيانات Google Web/Android أو Apple Services ID الفعلية؛ لذا لا يمكن التحقق من قبول OAuth على الدومين النهائي حتى تُسجّل redirect/return URLs وتُضاف client IDs إلى بيئتي الموقع والسيرفر.
- موقع iPhone مبني ومخدوم محليًا، لكن لا Chromium ولا iPhone فعلي متاح هنا: لم يُنفّذ اختبار متصفح مرئي أو تدفق OAuth/GPS على Safari. يلزم إبقاء Safari نشطًا أثناء الوردية؛ لا تتبع GPS ويب في الخلفية عند قفل الشاشة.
- لم تُختبر إشعارات Push على هاتف حقيقي؛ ما زال إعداد FCM v1 لـAndroid وبناء APK وتجربة الجهاز مطلوبًا. فحوص `mocked` ليست بديلًا عن Play Integrity ضد عميل معدل.
- لم يُجرَ نشر VPS أو اختبار HTTPS/النسخ الاحتياطي المجدول على خادم إنتاج؛ استخدم إعدادات `docs/DEPLOY-VPS.md` واختبر الاستعادة هناك.

النتائج أعلاه تثبت الفحوص المسماة فقط، ولا تدّعي اعتماد نسخة متجر أو اختبار جهاز فعلي.
